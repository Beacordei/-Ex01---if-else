# Descrição da composição interativa
**if/else**

Neste trabalho explorei como usar o if/else para criar interações com o rato e o teclado. As formas mudam entre amarelo pastel e rosa conforme a posição do rato. Ao clicar/pressionar (mouseIsPressed), os círculos transformam-se em quadrados maiores e, ao pressionar uma tecla (keyIsPressed), o ecrã é limpo. As formas aparecem em quatro posições simétricas sobre um fundo bordô escuro, criando um efeito de luzes suaves que desaparecem aos poucos.

Parti do exemplo da aula para começar. Usei o Claude como apoio para compreender a simetria e fui fazendo e adaptando o restante código.
